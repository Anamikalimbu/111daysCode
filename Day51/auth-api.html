User Auth_
API Reference

A stateless JWT-based authentication system for managing user registration, login, session tokens, and account lifecycle operations.

Base URL https://api.example.com/v2/auth
Bearer Token Authentication

Protected endpoints require a valid JWT in the Authorization header. Tokens expire after 15 minutes. Use the refresh endpoint to obtain a new access token without re-login.

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

User Registration

POST /register Create a new user account ▶

Creates a new user account. Validates email uniqueness, hashes the password with bcrypt, and returns a signed JWT access token along with a refresh token.

Request Body
FieldTypeRequiredDescription
email string REQUIRED Valid email address. Must be unique.
password string REQUIRED Min 8 chars. Must include a number and uppercase letter.
username string REQUIRED 3–32 characters. Alphanumeric and underscores only.
full_name string OPTIONAL User's display name.
Request Example
POST /v2/auth/register Content-Type: application/json { "email": "anu@example.com", "password": "Secure#Pass9", "username": "anu_dev", "full_name": "Anu Sharma" }
Responses
201 Account created successfully. Returns tokens.
{ "user": { "id": "usr_01j8xkt...", "email": "anu@example.com", "username": "anu_dev", "created_at": "2026-06-03T10:00:00Z" }, "access_token": "eyJhbGci...", "refresh_token": "dGhpcyBpcyBh...", "expires_in": 900 }
409 Email or username already in use.
400 Validation failed. Check field constraints.

Login

POST /login Authenticate and obtain tokens ▶

Verifies credentials and issues a new JWT access token and refresh token. Returns the user object on success.

Request Body
FieldTypeRequiredDescription
email string REQUIRED Registered email address.
password string REQUIRED Account password.
Request Example
POST /v2/auth/login Content-Type: application/json { "email": "anu@example.com", "password": "Secure#Pass9" }
Responses
200Login successful. Tokens issued.
{ "user": { "id": "usr_01j8xkt...", "email": "anu@example.com" }, "access_token": "eyJhbGci...", "refresh_token": "dGhpcyBpcyBh...", "expires_in": 900 }
401Invalid credentials.

User Profile

GET /me Fetch the authenticated user's profile ▶

Returns the full profile of the currently authenticated user. Requires a valid Bearer token in the Authorization header.

Headers
HeaderValueRequired
Authorization Bearer <access_token> REQUIRED
Response — 200 OK
{ "id": "usr_01j8xkt...", "email": "anu@example.com", "username": "anu_dev", "full_name": "Anu Sharma", "created_at": "2026-06-03T10:00:00Z", "last_login": "2026-06-03T12:45:00Z" }
401Missing or expired token.

Token Refresh

POST /refresh Obtain a new access token ▶

Issues a new access token using a valid refresh token. Refresh tokens are valid for 7 days and are rotated on each use (old token is invalidated).

Request Body
FieldTypeRequiredDescription
refresh_token string REQUIRED The refresh token from a previous login or refresh.
Response — 200 OK
{ "access_token": "eyJhbGci_new...", "refresh_token": "dGhpcyBpc_new...", "expires_in": 900 }
401Refresh token invalid, expired, or already used.

Logout

POST /logout Invalidate current session ▶

Revokes the provided refresh token and adds the access token to the server-side denylist until its natural expiry. Use this to cleanly terminate a session.

Headers
HeaderValueRequired
Authorization Bearer <access_token> REQUIRED
Request Body
{ "refresh_token": "dGhpcyBpcyBh..." }
200Session terminated successfully.
{ "message": "Logged out successfully." }

Account Deletion

DEL /me Permanently delete account ▶

Permanently deletes the authenticated user's account and all associated data. This action is irreversible. Requires password confirmation.

Request Body
FieldTypeRequiredDescription
password string REQUIRED Current password for confirmation.
200Account deleted permanently.
401Incorrect password or invalid token.
